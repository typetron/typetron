# Typetron Application Guide

## Framework Documentation

This project uses `@typetron/framework`. Before working with Typetron APIs, read the installed [Typetron Framework Guide](node_modules/@typetron/framework/AGENTS.md), then read only the module documentation it links for the area you are changing.

Treat the documentation under `node_modules/@typetron/framework` as the source of truth for the framework version installed in this project.
